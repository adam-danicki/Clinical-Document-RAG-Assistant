# Frontend for Clinical Document RAG Assistant

This folder contains a React + Vite frontend scaffold for the Clinical Document RAG Assistant.

## Getting started

1. Open a terminal in `frontend`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the app in your browser using the URL printed by Vite.

## Next steps

## Backend

The backend runs separately in `backend/` and is expected to listen on `http://localhost:8000`.
